# 针织行式编译台

用 **Python Flask + 原生 JavaScript/SVG** 实现的针织行式编译台：设置起针数后，
可先在「片段定义」区编写可复用的针法片段（`名称 = 序列`，行内 `@名称` 引用，
支持相互/前向引用），再逐行编写针法；系统按前一行针数（含片段实际展开）展开
当前行并推导下一行针数，源码、定义、展开结果与 SVG 图解四方联动。

## 快速启动（单命令）

```bash
docker compose up --build
```

然后访问 **http://localhost:8000**（端口：**8000**，可在 `docker-compose.yml` 的
`ports` 中修改宿主机侧映射）。

### 本地开发（不用 Docker）

```bash
pip install -r requirements.txt
python app.py          # 同样监听 8000 端口 → http://localhost:8000
```

### 运行测试

```bash
python -m unittest -v  # 46 个编译器单元测试，不依赖 Flask
```

## 针法与语法

| 记号    | 含义           | 消耗 | 产出 |
|---------|----------------|------|------|
| `k`     | 下针           | 1    | 1    |
| `p`     | 上针           | 1    | 1    |
| `yo`    | 挂线（空加针） | 0    | 1    |
| `k2tog` | 两针并一针     | 2    | 1    |

- **分组重复**：`(…)xN`，可任意嵌套，如 `(k k, (p, yo)x2, k2tog)x4`。
- **行末重复**：`*…*` 只能出现在整行末尾、不能嵌套。设其内部单次消耗为 `C`、
  当前余针为 `R`：仅当 `C > 0` 且 `R % C == 0` 时，恰好重复 `R / C` 次织到行末；
  否则报错并给出余针数。片段按实际消耗计入 `C`。
- 分隔符：空白、`,`、`，`、`、`；大小写与全角括号/星号/等号/`@` 均可识别。
- 数字不能直接跟在针法后（`k3` 不合法），重复请写 `(k)x3`。

## 片段（多行复用）

在左上「片段定义」区按 **`名称 = 针法序列`** 逐行定义，行源码用 **`@名称`**
引用；每次引用都就地展开为该片段的实际针法。

```
edge = k k
pair = yo, k2tog
body = @edge, (@pair)x2
```

```
(@body)x2          # = (k k, (yo k2tog)x2)x2
k k k k, *@pair*   # 行末重复按 @pair 实际单次消耗（2 针）计算次数
@edge, (k, yo, k2tog)x6, @edge
```

规则：

- 片段可**相互引用**、也可**前向引用**（先用后定义）；名称以字母或下划线开头，
  其后可含数字与下划线，也支持中文（如 `边 = k k`、`@边`、全角 `＝`/`＠`）。
- 片段内**只能写针法 / 分组 / 引用**，不能写行末 `*…*`（行末重复必须写在编织行上）。
- 编译时按每次引用展开；分组重复次数、行末 `*…*` 的整除与重复次数，均按片段
  **实际消耗/产出**计算。修改任何定义后立即重算所有引用行与后续行。
- **未被任何行（传递）引用的片段，即使内容写错也不影响正常行**——它只在定义区
  行号上标 `⚠`（点击可跳到错误列），未引用的定义行号灰显。
- 缺失引用、循环引用、被引用片段的语法错误，都定位到**使用它的编织行的
  `@引用` 列**，消息中给出引用链与所涉定义；可另点按钮跳到定义中的具体位置。
  出错行之后各行仍按原规则标记「未计算」。

**双端定位**：展开列表中来自片段的针法带角标 ⌖，SVG 格元右上角同样有 ⌖：

- 点击针法/格元本体 → 选中**实际针法所在定义**的源码列；
- 点击 ⌖ → 选中**本次行内引用** `@名称` 的源码列；
- 同一片段被引用多次时，各次展开分别指向各自的行内引用，互不混淆。

## 编译规则

- 第 1 行消耗「起针数」，之后每行消耗 = 上一行产出（含片段展开后的产出）。
- 每行消耗必须**恰好**等于可用针数：**不得截断、不得补针**。
- 错误三元组定位：**行号 + 字符列号 + 余针数**（片段错误的行侧列号指向行内
  `@引用`，并附 `loc` 指向定义），例如
  `第 2 行 · 第 1 列 · '*…*' 单次消耗 3 针，不能整除余针 20（20 % 3 = 2）｜ 余针 20`。
- 某行出错后，后续行针数无法推导，标记为「未计算」；修正后自动重算后续所有行。

## 界面联动

- **片段定义**（左上）：每行 `名称 = 针法序列`，编辑后 200ms 防抖与行源码一起
  重编译；行号对有问题的定义显示 `⚠`（点击定位），未被引用的定义灰显。
- **行源码**（左下）：每行一行针法，用 `@名称` 引用片段；编辑后自动重编译。
- **展开结果**（中）：逐行显示 入→出 针数、展开后的针法序列与本行片段引用链；
  点击针法定位**定义**，角标 ⌖ 定位**行内引用**；错误旁提供「定位引用 /
  定位定义」按钮。
- **SVG 图解**（右）：第 1 行在底部，每格一个产出针（k 竖线 / p 横线 / yo 圆圈 /
  k2tog 斜杠），行右标注产出针数；**点击格元定位定义、角标 ⌖ 定位行内引用**，
  悬停显示行号、针位以及定义/引用两侧的源码列。
- 光标在行源码中移动时，对应行卡片与图解行号同步高亮。

## 项目结构

```
app.py               Flask 入口（GET / 与 POST /api/compile）
compiler.py          词法/语法/片段表/展开/逐行推导（纯 Python，可单测）
test_compiler.py     46 个单元测试
templates/index.html 单页界面（片段定义区 + 行源码区）
static/app.js        前端联动、片段双端定位与 SVG 渲染
static/style.css     样式
Dockerfile           python:3.12-slim + gunicorn（8000 端口）
docker-compose.yml   单服务，映射 8000:8000
```

## API

`POST /api/compile`

```json
{
  "castOn": 24,
  "definitions": [
    "edge = k k",
    "pair = yo, k2tog",
    "body = @edge, (@pair)x2"
  ],
  "rows": ["(@body)x2", "k k k k, *@pair*"]
}
```

`definitions` 可省略（向后兼容）。响应顶层新增 `defs`（逐定义的
`line` / `name` / `used` / `status` / `error`）；每行包含 `status`
（`ok` / `error` / `blocked`）、`in` / `out` 针数、`stitches` 或 `error`。

`stitches` 中每个针法同时带两套定位：

- `s` / `e`：实际针法所在源码列（在片段内即为定义行列）；
- `rs` / `re`：本次**行内引用**的列区间（非片段针法时与 `s`/`e` 相同）；
- `def`：实际针法所在定义 `{name, line, s, e}`，行内直接书写时为 `null`。

同一片段的多次引用各自保留独立的 `rs`/`re`，不会混淆。`error.loc` 为可空的
第二定位：`{"source":"def",...}`（实际出错的定义）、
`{"source":"dref",...}`（父定义中出错的引用）或
`{"source":"row",...}`（循环引用闭环处的行内引用）。

安全上限：起针 ≤ 2000，行数 ≤ 500，片段定义 ≤ 200 行，单行 ≤ 2000 字符，
分组重复 ≤ 999，单行展开 ≤ 20000 针（超出即报错而非耗尽资源）。
